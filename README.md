•# 星视界 (xingshijietv)

一款简洁高效的 Windows 桌面端 IPTV 播放器，基于 Flutter 构建。

## 功能特性

### 播放
- 支持 M3U/M3U8、TXT、CSV 等多种直播源格式
- 支持 MP4/MKV/FLV 等视频直链播放
- 支持抖音短视频直链播放
- 内置央视网直播源（CCTV-1 至 CCTV-17 等）
- 支持全屏模式，鼠标移到底部显示控制栏
- 右侧悬停频道列表，一键切换频道

### 频道管理
- 在线 URL 导入直播源
- 本地文件导入直播源
- 播放列表分组管理
- 收藏频道
- 频道搜索
- 自动记忆上次观看的频道，下次启动自动续播

### 界面
- 多种主题：深色/浅色/GitHub 深色/GitHub 浅色
- 侧边栏导航：列表、频道、直播、收藏、搜索、设置、备份、关于
- 启动加载动画
- 响应式布局，支持窗口缩放

### 其他
- 数据备份与恢复
- 检查更新功能
- 多编码自动识别（UTF-8/GBK/GB18030/Big5）

## 系统要求

- Windows 10 / Windows 11（64位）
- 支持 WebView2（Windows 11 内置）

## 安装与使用

1. 下载 xingshijietv.exe
2. 双击运行即可，无需安装
3. 首次启动自动播放内置央视频道
4. 在"列表"页面导入你的直播源 URL 或本地文件
